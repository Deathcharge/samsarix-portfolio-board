# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [support@samsarix.com](mailto:support@samsarix.com). Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Do not include real access tokens or private repository data.

Please do not open a public GitHub issue for an unpatched vulnerability. Samsarix LLC will acknowledge a complete report as soon as practical, investigate it, and coordinate disclosure when a fix is available.

## Supported versions

Security fixes are provided for the latest minor release only.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| Earlier versions | No |

## Scope reminders

Samsarix Portfolio Board is a read-only dashboard. Activity labels are derived from GitHub metadata and are not security, build, deployment, or uptime assessments. Operators are responsible for protecting environment variables, terminating TLS, and applying appropriate network controls to public deployments.
