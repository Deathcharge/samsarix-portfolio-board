# Support

## Questions and reproducible bugs

Search the [documentation](README.md) and [existing issues](https://github.com/Deathcharge/samsarix-portfolio-board/issues) first. If the problem is reproducible and non-sensitive, open a GitHub issue using the appropriate template and include the application version, Node.js version, configuration with secrets removed, expected behavior, and actual behavior.

General support questions may be sent to [support@samsarix.com](mailto:support@samsarix.com).

## Security and private information

Do not post credentials, private repository names, customer information, or suspected vulnerabilities in an issue. Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Support boundary

The supported project is the latest minor release running on a supported Node.js version. Samsarix LLC does not operate user deployments and cannot administer third-party GitHub accounts, DNS, TLS, proxies, firewalls, containers, or hosting platforms on a user's behalf. Best-effort community support does not include a guaranteed response or resolution time.

Commercial or licensing inquiries may be sent to [contact@samsarix.com](mailto:contact@samsarix.com).
